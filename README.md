Project: Internship Market Intelligence

Problem: Students struggle to understand which technical skills employers value across different internship categories.

Goal: Analyze Canadian internship postings to identify skill demand and build a machine learning classifier for internship categories.

First milestone: Obtain a sample dataset of 100–300 postings and determine whether it contains enough usable information for analysis.

First deliverable: A Jupyter notebook showing job counts, skill frequencies, missing data, and initial insights.
